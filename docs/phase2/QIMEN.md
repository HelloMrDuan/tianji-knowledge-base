# 奇门具名输出与 variant

`qfdk-exact-term-midnight-v2` 固定节气时刻、符头三元表与转盘寄宫约定，不合并置闰、超接或飞盘。上游“茅山派”标签只作为原实现命名，不能据此宣称统一了所有该派算法。

`stars` 保留八外宫的“禽芮”合写标签；`star_positions` 展开九个具名星，天禽与天芮按此variant同宫。`door_positions` 与 `deity_positions` 各包含八个具名门/神。值符同时返回原标签和具名 `names`，中宫寄法不会被隐藏成独立第九外宫。

这些新增字段只是固定盘面表达，不新增排盘算法计数或改变既有星位。原有C原文关系、软件旋盘约定与精确历法D仍按 trace 的证据适用范围输出。
