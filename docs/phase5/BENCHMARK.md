# Phase 5 网站 Benchmark：交互与信息架构

研究日期：2026-10-02。仓库基线：main `9433a8b659d288bfa4b769e2d278221f2f1b3cef`；六域执行与 API 代码相对 `bbb439e` 未变。本次只提交研究与原型说明，没有开发前端、引入竞品代码或新增算法。

建议采用“先生成确定性盘面，再按需查看规则、依据、推演和解释”的网站结构。最有依据的参考是命语的盘面/助手工作区、就地术语释义，Chinese-Metaphysics-Platform 的知识目录/典籍精读，以及 MingPan 的结构化结果/可读文本双输出。古籍来源等级、流派贯穿、计算 trace 和 AI 审核状态来自本仓库约束，不能冒称竞品已有同等保障。

**这是有限证据版 Benchmark。** 三个开源项目完成固定 commit 的文档和相关源码审阅，并查看命语两张公开移动截图；问真、元亨页面和命语在线站点被当前环境出口代理拒绝，易百查尚缺可确认的官方链接。因此，六个对象均有逐项条目，但三个商业产品的真实页面体验对比尚未完成。未知项不能参与排名或成为已验证设计依据。完整来源、访问失败和后续核验方法见 [SOURCES.md](SOURCES.md)；方案见 [IA_AND_PROTOTYPES.md](IA_AND_PROTOTYPES.md)。

## 9. 采纳与拒绝的模式

| 模式 | 决策 | 依据与原因 |
| --- | --- | --- |
| 总盘 + 点选宫/爻详情 | 采纳 | 命语、平台源码；保护盘面空间关系，详情无需塞进格子 |
| 同一结果的图形与文本表达 | 采纳 | MingPan 双输出/renderer；提高可读性和无障碍，不重复计算 |
| 术语就地释义 | 采纳 | 命语释义组件；解释陌生术语时仍能看到当前盘位置 |
| 知识目录与典籍阅读分别入口 | 采纳，内容发布另受能力约束 | 平台知识页；浏览学习与核对引用是不同任务 |
| 盘面完成后按需 AI | 采纳 | 平台可展开面板、元亨独立插件、命语盘面/助手分区；对应 explain=false/true |
| 每域专用深链接，共用执行工作区 | 采纳 | 元亨页面清单、两前端路由；熟练用户直达，本站 API 保持单入口 |
| 手机上的总览与单项详情分开 | 采纳 | 命语移动截图/响应式组件；保留宫位定位，减少过密文字 |
| 多域合参、命运 K 线、吉凶百分比 | 不纳入 | 超出现有六域结构算法和证据；不能把可视化当作有效性证明 |
| 手机整体缩小桌面盘、只能 hover、默认所有专题展开 | 不采用 | 这些是通用可用性风险；不把它们无证据归到三个未实测产品上 |
| 自动生成解释、流式展示未校验正文、默认让用户填模型密钥 | 不采用 | 与当前解释校验、环境变量和未完成真实校准的边界不符 |
| 用“古籍数量/命中数量/绿 CI”表示结论可信度 | 不采用 | 本库 A/B 独立来源仍为 0；结构正确和证据充分是不同条件 |

不能直接宣称“问真新、元亨旧、易百查全”，也不因装饰风格就作产品优劣排名。真正不适合本站的是掩盖计算约定、证据等级或解释失败的交互。

## 10. Phase 5 决策与剩余核验

采用 [页面原型说明](IA_AND_PROTOTYPES.md) 的六域工作区。当前可直接映射的内容是 chart、rule_matches、trace、evidence、warnings、limitations；RAG 与 AI 是解释链的一部分。独立知识浏览/搜索的公开接口、持久化盘档、分享链接、追问和 SSE 尚不存在，不能在原型中写成已能调用。

正式视觉设计前，需要补问真、易百查、元亨的直接页面观察，并在手机尺寸上验证导航、输入口径、本变卦对齐、宫位详情、引用返回和解释失败状态。详见 [后续实测清单](SOURCES.md#后续实测清单)。真实模型校准是 AI 自动公开解释的独立阻塞，不因本报告通过而解除。
