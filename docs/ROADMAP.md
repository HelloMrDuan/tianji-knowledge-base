# Roadmap

## P0 当前
- GitHub 来源注册表 / 自动发现
- 许可证隔离
- 五行、天干、地支、八卦、64 卦结构
- 六爻纳甲基础
- 数据校验与上游 SHA 检查

## P1 周易底座
- 64 卦卦辞
- 384 爻爻辞
- 彖传、象传、系辞、文言、说卦、序卦、杂卦
- 公版版本校对与文本异文管理
- 错综综互、变卦关系图

## P2 确定性计算
- 历法 / 节气 / 干支
- 八字排盘
- 六爻纳甲
- 紫微
- 奇门
- 梅花
- 六壬
- 太乙

## P3 专业知识包
- 八字：十神、格局、调候、用神、大运、神煞、经典
- 紫微：星曜、庙旺、四化、三方四正、格局
- 奇门：九宫、九星、八门、八神、用神、格局、不同起局法
- 六爻：月建日辰、旺衰、用神、动变、冲合刑害、应期
- 风水：流派隔离，不混用玄空/八宅等口径
- 姻缘：建立在八字/紫微/生肖等透明规则上
- 塔罗：使用授权明确的数据源

## P4 服务化
- PostgreSQL + pgvector
- 全文 + 向量混合检索
- domain/school/source_level/license/confidence metadata filter
- Citation-first API
- MCP / Agent / 网站统一接口

## P5 质量
- 黄金排盘集
- 冲突检测
- 检索召回率测试
- 引用准确率测试
- AI 幻觉评测
