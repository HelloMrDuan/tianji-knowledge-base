# 风水 Phase 1 证据边界

正式术语使用《葬书》及旧注、《撼龙经》/《疑龙经》传世本、
蒋大鸿《地理辨正》《阳宅指南》和朱熹《周易本义》短选段。
旧题作者、电子本具体注家未确证者明确注明；只审核本轮引用片段。
四兽是相对穴处的前后左右，不擅改成固定方位。朝案分别保留朝山、案山依据。
对三合、八宅的蒋氏批评不改写成被批评流派自身的定论。

河洛、八卦、干支及二十四山复用现有共享数据；新接口不改动这些旧文件。
二十四山15度区间属于既有罗盘数学约定，不假称古籍原句规定了现代度数。

三元九运的9行结构化研究表记录元、运、起止年份、洛书宫、卦与五行，
位于 `data/quarantine/phase1/fengshui/periods.json`，证据为 D。
目前所查古籍能定位“三元”术语，尚不能证明该软件所用1864锚点及每运20年表。
不以“轮转三元”一句冒充具体年份依据，也不把旧实现的公历年边界冒称立春。
研究接口必须显式传 `research=True`；新增研究表不进入默认生产索引。
现有 Canonical `calculation_v1.json` 按用户要求保持稳定，其旧表不会因这次
注册新实体而被重新认定为有古籍核定的新规则。

本域 Phase 1 建立可定位的术语、原典、规则、共享实体引用与审核边界。
玄空完整山向飞星、替卦、兼向、时间边界和新吉凶规则均不在本轮声称的
执行能力内。三元九运时间表的原典版本证据仍列为待核事项。
