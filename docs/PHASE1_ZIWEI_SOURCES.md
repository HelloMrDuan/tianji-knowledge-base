# 紫微 Phase 1 版本说明

十四主星与十二宫引用《紫微斗数全书》古籍选段。电子本来自
hxl888/jingpan 的固定提交；其 `bookSources.json` 指明底文为国学典籍网
`http://ab.newdu.com/book/ms261794.html`、`ms261795.html`、`ms261796.html`。
本轮仅保留古籍短选段，不复制网站代码、现代白话、拼音括注或完整现代整理本。
本源无已核定原刊本，证据定为 C，不能据此升为 A/B。
旧题陈希夷不当作已证实宋代作者或成书年代。

问答论与五行条目有不同表达，例如贪狼水／水木、天同水／水金。
新实体保留原句，不回填现有 iztro 的空属性。安天魁钺歌丙丁“猪狗”
与现代实现“猪鸡”不一致，仅保留为部分结构化规则，暂不执行其全部口诀。
壬年四化句“府／辅”未核刊本，只存隔离候选；不改变现有四化表。

六吉所指左辅、右弼、文昌、文曲、天魁、天钺，六煞所指擎羊、陀罗、
火星、铃星、地空、地劫均已有独立术语与原文定位。
本书空劫诀的“天空”只在该版本中映射为检索名“地空”，不建立全局同名等价。
长生男顺女逆的原文与现代阴阳男女配置并存，不形成唯一完整排盘算法。

《万历续道藏·紫微斗数》三卷本经初步检查属于另一套星曜系统，留作独立
书目候选。《紫微斗数全集》本轮未取得来源、版权范围及版本均足够明确的
电子本，只留候选元数据。不会用现代教学书替代原典。
