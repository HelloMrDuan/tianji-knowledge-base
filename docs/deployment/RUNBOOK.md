# 天机 v0.1 受限内测｜部署运维手册

> 范围：受控环境部署。生产公网发布需另行授权（域名、TLS 证书、网关）。

## 1. 健康检测

| 检查 | 地址 | 期望 |
|---|---|---|
| API 存活 | `GET /health` | 200，无鉴权 |
| 前端 | `GET /`（经 nginx） | 200，静态页 |
| 公开能力 | `GET /api/v1/capabilities` | 200，无私有标记 |

Docker healthcheck 已内置（30s 间隔）。网关层应对 `/health` 做主动探测，
连续 3 次失败即摘除节点并告警。

## 2. 备份

- **备份对象**：私有知识目录（只读挂载源）、`TIANJI_ADMIN_READ_TOKEN` 等密钥（密钥库）、
  compose 文件与本次部署的镜像 digest。
- **备份频率**：每次部署前快照；每日增量。
- **验证**：备份后对快照做哈希抽查并记录；未验证的备份视为无效。

## 3. 回滚

1. 停止当前 compose：`docker compose -f deploy/docker-compose.yml down`
2. 用上一版镜像 digest 重新 `up -d`（digest 记录在部署日志）。
3. 等待 `/health` 连续 3 次 200。
4. 若健康检查失败，保持旧版本运行并告警，禁止带病上线。

回滚必须在 15 分钟内完成；超时则升级为事故。

## 4. 密钥红线

- `TIANJI_ADMIN_READ_TOKEN`、`TIANJI_AI_API_KEY` 只来自密钥库/环境，**永不**写入
  仓库、镜像层、compose 文件或日志。
- 公开仓库中只允许 `.env.example` 占位；CI 扫描到真实密钥即阻断。

## 5. 发布边界（v0.1 受限内测）

- 仅开放已审核公开能力：八字/运势/桃花/事业/合盘/一事占问/解梦文化查询。
- 不开放：研究态大运交运日期、通用喜用神、未授权 AI 解梦、admin 治理接口（无 token 时 503 fail-closed）。
- 无依据时接口明确返回未裁定，不编造结论。

## 6. 外部阻塞清单（诚实记录）

| 阻塞项 | 状态 |
|---|---|
| 公网域名 | 未分配 |
| TLS 证书 | 未签发（网关层终止 TLS 前不得公网暴露） |
| 生产服务器/容器平台 | 未就绪 |
| 部署权限归属 | 待用户确认 |

在以上就绪前，仅做受控环境联调；**禁止伪造已上线地址或部署结果**。
