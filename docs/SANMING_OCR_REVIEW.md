### 第 39 批复核口径

扫描输入严格为 immutable raw → 86 个已确认 PUA 映射 → 前 424 条文本校勘。本批保留每处原字、恢复的历史字形、固定 commit / path 和局部原文证据；四库两套转录属同一版本体系，独立整理文本用于额外交叉验证，不将三个仓库等同于三个独立传本。

44 个差异位置均有两套历史转录一致的字形，以及独立维护文本中至少六个汉字侧翼的读法支持。相邻误字一并核验时采用历史见证的局部上下文，但 replacement 只改已确认的位置，不抄入旁边的版本差异。比较别名、简繁转换和去标点只用于对齐/检索；最终 old/new 保留 raw 中的其他字形和空白，每条 old 顺序回放必须唯一，new 不得预先存在。

本批包含“行羊刃歳运亦㓙”“歳运见䘮吊”“吉㓙未萌大运歳君”等过去锚点中尚未确认的位置，并保留“指定吉㐫”“弃命就财须要㑹财”等历史写法。PUA 校勘映射与 raw 文件不变；PUA 仍为 86/86、524/524、remaining=0；Canonical 输出文件持续不存在。

## 非“防”异常的处理

| 候选 / 差异 | 证据与决定 |
| --- | --- |
| 辛西 / 辛酉；庚辛西地祥 / 庚辛酉地祥 | Wikisource 系文本与 kanripo 的字不同；不凭干支语义统一 |
| 尊彼往哲 / 遵彼往哲 | 两套四库文本作“遵”，NiuTrans《金声玉振赋》作“尊”；作为版本/传写候选保留 |
| 身材琐小 / 身品𤨏小 | 四库文本与整理本存在混合字形差异，不能把“身品”假定为正确 OCR 恢复；保留 |
| 真珠 / 珍珠 / 𤤽珠 | 历史转录与整理本差异，未达到本轮一致性门槛；保留 |
| 己、已、巳 | 全文对比；历史文本在相同语境有互用字形，未做全局规范化 |
| 会/㑹、微/㣲、看/㸔、凶/㓙/㐫 | 正常字与异体字相当时保留；仅在 raw 为误识别字且有确证时恢复历史字形 |
| 缺字、赘字、倒置、标题差异 | 现代本的短片段命中会误配重复引文；不以此猜补或删除。图像占位符的描述也不能当正文 |

本轮目前能够直接可靠确认的条目仍以异常“防”占位读法为主，这是两套全文扫描与证据门槛的结果，不是只扫描该字。没有把对照版本自身的 OCR、异体字或现代整理改文倒灌为原文校勘。
