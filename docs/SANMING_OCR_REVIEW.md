## 非“防”异常的处理

| 候选 / 差异 | 证据与决定 |
| --- | --- |
| 辛西 / 辛酉；庚辛西地祥 / 庚辛酉地祥 | Wikisource 系文本与 kanripo 的字不同；不凭干支语义统一 |
| 尊彼往哲 / 遵彼往哲 | 两套四库文本作“遵”，NiuTrans《金声玉振赋》作“尊”；作为版本/传写候选保留 |
| 身材琐小 / 身品𤨏小 | 四库文本与整理本存在混合字形差异，不能把“身品”假定为正确 OCR 恢复；保留 |
| 真珠 / 珍珠 / 𤤽珠 | 历史转录与整理本差异，未达到本轮一致性门槛；保留 |
| 己、已、巳 | 全文对比；历史文本在相同语境有互用字形，未做全局规范化 |
| 会/㑹、微/㣲、看/㸔、凶/㓙/㐫 | 正常字与异体字相当时保留；仅在 raw 为误识别字且有确证时恢复历史字形 |
| 缺字、赘字、倒置、标题差异 | 现代本的短片段命中会误配重复引文；不以此猜补或删除。图像占位符的描述也不能当正文 |

本轮目前能够直接可靠确认的条目仍以异常“防”占位读法为主，这是两套全文扫描与证据门槛的结果，不是只扫描该字。没有把对照版本自身的 OCR、异体字或现代整理改文倒灌为原文校勘。
