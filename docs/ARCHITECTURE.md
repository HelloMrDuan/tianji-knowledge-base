# Architecture

## 数据流

```text
GitHub / 公版古籍 / 人工整理
        ↓
   Source Registry
        ↓
 RAW → QUARANTINE → CANONICAL
                       ↓
          ┌────────────┼────────────┐
          ↓            ↓            ↓
     确定性引擎     全文/向量索引   RAG / Agent
```

## 四层知识

1. **L0 原典库**：周易、易传以及确认公版的古籍原文。
2. **L1 规则库**：五行、干支、十神、纳甲、四化、飞星等结构化规则。
3. **L2 流派/解释库**：不同门派、现代整理、案例；必须标流派和来源。
4. **L3 AI 使用库**：由 Canonical 生成的 chunk / index，不反向污染原始知识。

## 检索优先级

1. 确定性计算结果
2. 公版一手经典
3. 已确认流派的 Canonical 规则
4. 许可证明确的二手整理
5. Quarantine / Reference-only 不参与生产回答

## 冲突处理

不同流派的规则不互相覆盖。例如奇门拆补法与置闰法应分别保存为不同 ruleset。平台运行时先选择 ruleset，再检索对应知识。

## 晋级门槛

资料进入 Canonical 前必须同时满足：

- 来源可追溯；
- 许可证允许目标用途；
- 已去广告、prompt 包装、重复内容；
- 客观计算事实与解释文本已分离；
- 可能有分歧的内容已标注流派；
- 结构校验通过；
- 关键算法表尽量配黄金回归案例。
