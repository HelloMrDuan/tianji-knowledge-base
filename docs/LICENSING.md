# Licensing Policy

本仓库代码为 MIT，第三方资料保持各自许可证。

## 策略

- **ALLOW**：MIT / Apache-2.0 / BSD / ISC / CC0 等明确宽松许可证，可按条款进入清洗流程。
- **PUBLIC_DOMAIN_EXTRACT_ONLY**：仓库本身无许可证，但其中明确属于公版的古籍原文/客观结构可独立提取；现代解释不复制。
- **REFERENCE_ONLY**：用于研究、冲突比对、寻找上游原典，不直接进入商业 Canonical。
- **NON_COMMERCIAL**：包含 NC 条款，商业生产库默认排除。
- **COPYLEFT**：GPL/AGPL 或混合许可证，必须单独评估义务，不能无脑混入 MIT 产品。
- **QUARANTINE**：许可证和来源尚未解决。

## 硬规则

1. GitHub 仓库公开 ≠ 内容可以自由商用。
2. 无 LICENSE 默认不是 ALLOW。
3. 古籍尽量回溯公版版本，不连同现代作者注释复制。
4. 混合许可证按子目录/文件处理。
5. GitHub 派生知识必须保留 repo/path/commit/license 元数据。
