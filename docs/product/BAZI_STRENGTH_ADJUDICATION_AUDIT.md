## 实施顺序和验收边界

2. 根 availability 三层定性；首次限定已审核木根，不推未审核四库。
3. 实际作用只在有根、无未解改变的已审核充分条件中执行；其余仍 unresolved。
4. 演进现有 `bazi_adjudication.py`，显式 `bazi-strength-adjudication-v1`；只取上述充分条件，返回 strong / weak / indeterminate。同一 Variant 必须同时通过正强、正弱、abstention、conflict 固定 Golden，并使用不同于古例的命盘复算；有真实历法输入的正例尤其需要保留。
