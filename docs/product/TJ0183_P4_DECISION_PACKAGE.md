### 3.1 UD-1：RD-12 十二条是否定单一读法

**问题陈述。** RD-12 十二条的四库谱系读法与现代谱系簇读法逐条相异（§1.6 全表），现按默认 A 并列登记、S3 工作本保留快照字。只有当未来某个 canonical 文本（或逐节晋级产物）要求每处只能有一个字时，才必须在十二条上定单一读法；工作本现状并不要求。

**证据基础。** P3 登记册 `sanming-reading-disagreement-collation-register-v1`（E0324）十二条逐条互校记录（双方读法、语境、谱系归属、内证观察）；设计 §4.2 判定标准：可择一当且仅当 (a) 出现与两簇均独立的第三谱系见证证实其一，或 (b) 逐条内证决定性成立并逐条登记。实测：(a) 十二条均无第三谱系见证（0 条）；(b) 内证逐条登记为观察、无一条被登记为决定性（853/931 内证较强、612 倾向现代读法一侧，均照实登记强度但未达采纳门槛）。seq 450 另注：两读文义皆通、内证不显然，设计在案预期并列。

**选项全文**（设计 §5.3 登记原文口径）：

- **A 并列登记保留快照字（默认）**：十二条维持现状——并列登记、快照字保留、不下裁定；待第三谱系见证或决定性内证出现时以订正事件逐条重开。
- **B 全批采四库读法**：十二条一次性全采四库谱系读法为单一读法，S3 后续版本据此改字。
- **C 逐条裁定**：互校登记基础上逐条报告、逐条裁定（每条可分别采四库 / 采现代 / 维持并列），仅裁定条目据裁定改字，未裁定条目保持并列。

**设计建议**（设计 §5.3 在案）：A 为默认；若需择一则走 C、**不走 B**。理由：现有证据是谱系对谱系的一对一僵局，全批 B 等于以谱系偏好代替逐条证据，且 4 条「四库同词仅字形异」条目（784/853/880/931）的实在分歧在现代侧异词、全批采四库并不能由证据推出；逐条 C 至少使每条的取舍各自承担证据说明。

**各选项后果与执行形态。**

| 选项 | 后果 | 后续执行形态 |
|---|---|---|
| A | 十二条长期并列；下游若需单一读法的场景逐处标明未定 | 无执行批；新见证出现时逐条订正重开 |
| B | 十二条一次定谳，但与现行证据状态相悖的风险全量落账（尤其内证倾向现代侧的 612 等条目被反向定谳） | v2 应用批改 S3 十二位点字 + 换代四步 + 全量回归；P3 登记册以订正事件追加裁定记录 |
| C | 逐条定谳、逐条担责；未裁定条目（预期含 seq 450）继续并列 | 逐条裁定批（呈请—裁定逐条入册）→ 仅就已裁定条目走 v2 应用批改字 + 换代四步 + 全量回归 |

### 3.2 UD-2：永久缺口 2 处是否以提议读法补字

**问题陈述。** S3 工作本有 2 处 □（§4 专节）：「谬□甚矣」与「王麟洲少□」。两处提议读法（误 / 卿）的证据均非底本证据，是否破例补字，属用户裁定。

**证据基础。** 设计 §4.3 在案复核：「谬误甚矣」的证据为 sinan-app 现代转述本的释读，两家四库转录见证同位均保留「謬□甚矣」；「王麟洲少卿」的证据为中研院人物资料的履历旁证（王世懋擢南京太常少卿），能释读、不能证明本句缺字。两条状态均为 `needs_base_text_evidence_do_not_apply`；应用批已以 permanent_gaps 原样登记（审定点 AP4）。

**选项全文**（设计 §5.3 登记原文口径）：

- **A 保留 □ 为永久缺口（默认）**：两处 □ 永久保留，提议读法只作提案字段；重开条件唯一——出现底本级新证据（四库影印原叶或独立刊本同位文字），以订正事件重开。

### 3.3 UD-3：整书姿态——逐节晋级（整书保持 false）还是整书翻 true

**问题陈述。** P1–P4 全部完成后，《三命通会》整书的 `canonical_ready` 何去何从：维持「只走逐节晋级、整书永远保持 false」，还是在某个时点整书一次性翻 true。

**证据基础。** WBS TJ-018.3 形制本身即「每个审核场景独立审批 + 整书仍保留审批红线」；设计审定点 AP6 已登记立场：整书不建议翻 true，此为设计立场登记、决策权在 P4 与 UD-3。现状事实：S3 是经全核与全量应用的工作本，其 993 候选、769 残余防、12 条 RD-12、2 处缺口的处置深度逐项不一（§1），且 UD-1/UD-2 尚有未定项——整书翻 true 将把这些深浅不一的状态一次性背书为 canonical。

**选项全文**（设计 §5.3 登记原文口径）：

- **A 只走逐节晋级、整书 canonical_ready 保持 false（设计立场）**：后续按节走独立 Source/Section/Term/Rule/Evidence/Golden 审批，逐节把已审部分晋级；整书值永久保持 false，红线不撤。
- **B P1–P4 全完成后整书翻 true**：以本链成果为据，将整书 `canonical_ready` 一次性置 true。

**设计建议**（设计 §5.3 在案）：**A**。理由：与 WBS 形制一致；逐节晋级的粒度与各节校勘深度（383 条校勘记的覆盖面、逐节见证状态）相匹配；整书翻 true 与 UD-1（12 条无单一读法）、UD-2（2 处缺口）在未裁定状态下含义冲突——若先翻 true，等于默认替两项做了有利于「已定谳」的解释。

**各选项后果与执行形态。**

| 选项 | 后果 | 后续执行形态 |
|---|---|---|
| A | 整书红线永久在位；晋级收益按节兑现、逐节可审计 | 逐节晋级批序列：逐节坐标换算（S0→S3 经 origin 图）、逐节 Term/Rule/Evidence/Golden 建立与审批；不需整书换代动作 |
| B | 整书一次性成为 canonical；UD-1/UD-2 未定项被整书背书覆盖，事后逐条纠正的成本与账面冲突显著上升 | 整书晋级执行批：须先定义「未定项在 canonical 文本中的呈现规则」（本身即新的待裁定项）、整书级复核门、全量回归与换代四步 |

### 3.4 三项相互关系

- UD-1 与 UD-2 是**点状**裁定（12 个位点、2 个位点），UD-3 是**整书姿态**裁定；前两项的任一结果都不改变第三项的默认运行，反之亦然。
- 唯一需要注意的组合：**UD-3 选 B 时与 UD-1/UD-2 的关系**——若 UD-1/UD-2 仍维持默认 A（未定单一读法、缺口保留），整书翻 true 须先回答未定项在 canonical 文本中如何呈现，这会产生新的待裁定项；呈请建议：三项可同批回复，若 UD-3 意向为 B，请一并示意 UD-1/UD-2 的处理方式，或接受「先裁定 UD-1/UD-2、再执行 UD-3」的执行顺序。
- 无论三项如何裁定，B002 冻结、私有数据边界与 AI 关闭等 standing 红线均不受影响。
