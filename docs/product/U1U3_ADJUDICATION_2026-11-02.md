## Batch C 前端契约准备（仅规格，不含前端代码）

- 第二层（命中事实）：仅当 status == presented 时展示：谓词 id 对应
  的限定形态事实文案（固定为“已审强弱形态事实”）、strong/weak 分类、

- 第三层（公开证据引用与规则来源）：展示构建器给出的规则 id
  （Phase1 规则 id 或 Phase2 步骤 id）与证据引用（证据 id 与来源
  id）；不得展示研究本体、完整规则数据、密封原文或 Trace。
- 第四层（范围说明）：每种状态下都必须展示范围说明文案：
  “本呈现仅陈述已审充分谓词的命中事实；不是全盘旺衰判断，不意味着
  喜用神或吉凶；未命中不等于弱。”
  - presented：另说明“该结论只覆盖这一个已审形态，不覆盖全盘”。
  - not_judgeable：说明“本盘没有命中已审充分谓词，暂不可判；未命
    中不等于弱”。
  - conflict：说明“本盘存在未裁定的冲突，暂不可判；不作任何强弱
    结论”。
- 前端不得做的事：不得自行计算、推断或补全任何强弱结论；不得把
  presented 转写为身旺/身弱、喜用神、吉凶或运势预测；不得缓存、
  持久化或跨请求复用呈现对象；不得把 strength_presentation 与调候、
  病药合并为一个统一喜用结论；不得在 xiyong/dayun 呈现区之外复用
  其文案。
