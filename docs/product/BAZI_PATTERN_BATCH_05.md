# Bazi Pattern Batch 05：渊海正官时柱偏官限制

## 已审核来源

沿用已批准的 `bazi.section.s055`（《渊海子平·正官论》固定 C 级电子文本）：“若月令中有正官,时干支有偏官,便难以正官言之。”

该句不足以推导“官杀混杂＝破格”或整个格局成立/不成立；也不能将年/月柱的七杀误看成**时柱**偏官。

## 执行范围

在原有研究 `bazi-pattern-structure-candidates-v1`、`bazi.rule.r027` 和已执行十神/藏干 Phase2 中新增：

- `month_hidden_official`：月支藏干存在正官；
- `hour_visible_seven_killing`：时干显七杀；
- `hour_hidden_seven_killing`：时支藏七杀，不当作时干透出；
- 满足“月令正官 AND（时干七杀 OR 时支藏七杀）”时仅标识 `restriction_observed` 和 `additional_source_review_required`；
- `official.qualification` 仍为 `indeterminate / disqualified_for_this_branch`；`determination` 所有结论 null。

7 个 Golden 覆盖显干、支藏、并存、时柱无七杀、月令无官、年柱有七杀但时柱无七杀、时干正官非七杀。
固定测试检查事实引用、已执行原典 s055 Evidence 与 public/AI 关闭。
