# TJ-018-A 三命卷二两节校勘与逐条校勘记形制（首建）

本文件定义逐条校勘记的最小形制（TJ-018 校勘线各批通用模板），并记录
TJ-018-A 批（三命卷二《论天干阴阳生死》+《论五行旺相休囚死并寄生
十二宫》校勘与扩登记）的执行结论。登记数据本体在
`src/tianji_kb/bazi_sanming_juan2_collation.py`（纯数据、零函数），
本文件不替代登记数据。

## 一、校勘记最小形制（018-B..H 沿用）

每条校勘记是一个字典，字段如下：

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定标识，建议形如 `<节缩写>-<类别>-<字符偏移>`（本批：`sm2-pua-39492`、`sm2-fang-39147`、`sm2-ji-39571`、`sm2-yi-40755`、`sm2-si-39386`、`sm2-gap-42148`） |
| `section_id` | 所属登记节 |
| `char_offset` | 在钉定快照中的零起点字符偏移（UTF-8 码点） |
| `context_short` | 快照原文语境（本批取偏移 ±14 字），逐字保留原字 |
| `snapshot_glyph` | 快照原字（PUA 条目另带 `snapshot_codepoint`） |
| `reading` | 校定字；无法定字时为 `null`，原文保留 |
| `reading_status` | `confirmed` \| `contextual` \| `suspected` \| `unresolved`（口径见下） |
| `disposition` | `corrected`（订正）\| `genuine`（真义判定）\| `unresolved`（未决） |
| `basis` | 依据列表：`{kind, witness, locator, quote_short}`，`kind` ∈ `witness`（独立见证）\| `sealed_asset`（密封校勘资产条目）\| `same_section_corroboration`（同节互证）\| `context`（语境判定） |
| `usable_grade` | `Q1` 逐字引文 \| `Q2` 列举结构 \| `Q3` 立场证据 \| `null`（未决） |
| `note` | 读法说明、字形历史（历史字形保留，不现代化改写）、引用限制 |

等级口径（沿用既有先例，不新造无定义等级）：

- **confirmed**：≥2 个独立见证，或同节互证达到同等强度；密封校勘
  资产（PUA 映射表、603 条文字订正）的 confirmed 条目即按此口径
  产生，本项目逐条复核其见证锚点后才采信入册——候选只是流水线
  产物，定字权在本项目的逐批复核登记。
- **contextual**：语境定字或真义判定（密封 PUA 映射的语境映射类
  先例）；真义判定用于「逐处落账」要求覆盖、但原文不误的字
  （如「隄防」的防）。
- **suspected**：有结构依据（枚举槽位、对举结构）但未查外部见证，
  或属引述段材料；只登记读法提案，不作校定，引用避开。
- **unresolved**：拿不准。`reading=null`，原文保留并明示挂账，
  严禁猜改；该处不入任何登记引文。

配套纪律（全部批次一致）：

1. 校勘记寄存在该节的登记数据模块内（沿 Slice A/B/C 先例），不另
   建全局注册表；引文永远逐字保留快照原字，校定只进校勘记与
   `mapped_reading` 标注，不回写快照、不静默替换。
2. 校勘不得改义：只有形讹/PUA/多源汇讹且有互证依据者才校定；
   文义异文一律并列登记为 conflict 分支，不裁定。
3. 每批验收必须包含：范围内 PUA 逐处有校勘记、防逐处三分类落账
   （见证定字 / 存疑 / 真义判定）无遗漏、封闭枚举结构自洽扫描、
   登记引文对快照切片逐字等值 + 全文唯一性、合并前机上全配方
   复跑 0 失败。已校定引文另须可机检「原文切片经校勘记变换 ==
   登记校定读法」。

## 二、TJ-018-A 执行摘要

- 两节定位（机上实测）：《论天干阴阳生死》[38890, 43082)，分三段
  划界——逐干铺陈 [38890, 41810)、论曰总结 [41810, 42151) 为登记
  证据，论辩引述 [42151, 43082) 只存档；《论五行旺相休囚死并寄生
  十二宫》[54894, 55673) 全节登记。
- 校勘记 44 条：PUA 4（全 confirmed：惨/𦕈/燥/含）；防 11（三分类：
  定字 10、真义 1「隄防」）；己 13 + 已 6 逐处处置；巳干位槽 9
  （含 1 未决）；缺字 □ 1（未决，与 public_domain_manifest 既有
  挂账同处）。状态分布：confirmed 25、contextual 14、suspected 3、
  unresolved 2。火线审源点名的 2 处新订正（丙禄己→巳 39571、庚生
  已→巳 40755）在册；结构扫描另发现同类形讹 9 处（confirmed 7、
  suspected 2），按同一证据标准入册。
- 「防」多源汇再实证：本批 10 处定字的原字为 㓕/䌓/䘮/㣲/㦸/㑹/㡬
  七种互不相干字，「防代煞」在本批窗口 0 例；不存在全局替换规则。
- 十干覆盖核对：十干禄/生/死陈述俱全，无缺干（覆盖表在登记模块，
  锚点节内唯一性由密封专项钉住）。
- 丁长生 conflict：三命本节 + 神峰楠曰作酉 vs 神峰五行级四生作寅，
  两说并列不裁定。丙长生寅/禄巳/死酉三方一致（登记事实），但根表
  可推性结论为**部分可推**：帝旺无逐干逐字句、其余九宫逐干位属
  推步、丁冲突未裁三项未决，不宣布丙根表已审定。
- 密封资产对账：603 条订正落入两节窗口恰 5 条（ocr-001/024/052/
  132/474），全部按见证入册；66 条零匹配订正经子串与见证路径双向
  核查，与两节窗口无关联（归因属 018-H，本批不处理）。
- 未做：018-B..H 各批；66 条归因；火形态审定；任何旺衰谓词。
