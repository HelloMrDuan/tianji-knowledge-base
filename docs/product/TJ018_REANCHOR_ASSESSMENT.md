## 一、重锚结果（机上实测，方法可复算）

候选文件 `sanming_ocr_candidates.json` 自述 `offset_basis` 为
「raw → 86 PUA 映射 → ocr-001..444 应用后」的字符偏移。本批先
实测澄清一个口径问题：`baseline_character_offset` 指向**候选
位点本身**（`old` 串起点），不是 context 起点——位点在基线文本
中 993/993 逐字命中；context 是位点前后 28–59 字的窗口，位点
在 context 内偏移 3–25 字（众数段 18–22），逐条登记
`site_in_context`。

重建基线文本：带 origin 位点图的两阶段忠实复放——PUA 阶段
86 映射全等长、位置恒等（统一映射 85 条 1→1；U+E7E8 语境
4 规则等长替换）；文本阶段按 `apply_sanming_text_collation.py`
全规则（锚串恰 1 次、目标串预存校验、`allow_existing_target`
豁免）以文件序应用 ocr-001..444（仅 ocr-017 变长 16→15）。
产出 461,156 字、SHA256 `db8618c9…`，与仓库脚本
（`apply_pua_collation.py` + 过滤至 444 条的
`apply_sanming_text_collation.py`）实际运行输出**逐字等值**。

逐条逆映射结果（993 = 各类之和，登记册与密封专项可复算）：

## 二、TJ-018.3 晋级决策还缺什么（逐项）

按 018-H 路线备忘第 2–6 步与本批结果对账：

1. **PUA 整批应用批（未做）**：86 映射须在一份工作副本（非
   canonical 路径）上正式应用并产出应用报告（524 处、归零）；
   且映射码位的逐一复核覆盖率不足——本项目只逐批抽验过与已
   登记引用相关的码位，其余码位未逐一复核（审源 §7 在案），
   晋级决策前须给出抽核/全核口径与记录。
2. **文本订正整批应用批（未做）**：603 条全量应用在 018-H 与
   本批均已忠实复放证明可行（0 异常），但正式的工作本应用、
   应用报告与残余扫描（PUA 0、残余「防」769 处）尚未作为
   独立批次落账；工作本仍须保持 `review_status=in_progress`、
   `canonical_ready=false`，不得直升 canonical。
3. **残余「防」769 处处置（未做）**：无任何 confirmed 订正
   覆盖；沿 018-A..G 逐节校勘路线按需求面分批处置，或另立
   残余防归因批。「防」多源汇定性不变，全局替换永久禁用。
4. **76 条 context 不可锚候选的证据面处置（本批新增项）**：
   其位点全部可锚，终局化可按位点推进；但 context 级证据
   只能落在基线文本（PUA+444 中间态）上——晋级决策须明示：
   基线文本作为证据工件保留（本批已钉其长度/SHA256 与可
   复算方法），或对这 76 条逐条以位点为中心另行取证。
   其中 24 条「位于长订正内」的 context 跨订正域，其历史
   读法证据与订正域的关系须在终局化批逐条说明。
5. **12 条 reading_disagreement_hold 见证互校（未做）**：无
   互校结论前维持 hold；若互校涉及流派读法取舍，属用户级
   裁定，决策包须单列（本批实测：12 条位点全部 direct 可锚、
   context 11 可锚 1 跨界，坐标面无障碍）。
6. **47 条 variant_preserve / 775 条 historical_only_hold 的
   处置登记（未做）**：异文登记与历史读法定位的正式落账属
   终局化批；本批只确立其坐标（位点全可锚）。
7. **manifest 在案 unresolved_text_gaps 2 处（未处置）**：
   与既有逐节校勘记（累计 383 条）共同构成决策包输入，
   须在决策包中明示其对整书晋级的阻断口径（整书晋级 vs
   逐节晋级路径不受影响的边界）。
8. **版本冻结登记**：快照与三份 JSON 以现行 manifest 哈希
   为准冻结（本批已钉：快照 SHA256 `00e2a7db…`、候选 JSON
   SHA256 `4209b85d…`、基线文本 SHA256 `db8618c9…`）；流水线
   侧任何再生成都会使锚串前提与候选偏移同时失效，晋级前
   须登记版本对应关系。

**结论**：坐标面障碍已清零（位点 993/993 可锚、159 对应
关系确立、基线文本可复算钉值）；TJ-018.3 仍不可直接决策，
缺的是上述第 1、2 步的正式应用批与应用报告、第 3 步残余防
路线、第 5 步见证互校与第 8 步冻结登记——均为独立批次工作，
无一项需要改动本批登记。
