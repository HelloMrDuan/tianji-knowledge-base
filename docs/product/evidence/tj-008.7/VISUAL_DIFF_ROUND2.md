## 仍未达到原图的具体差异（诚实记录）

1. 原图楼阁为多人庭院大场景（含多盏灯笼、更密的梅枝、更丰富的案头陈设）；
   本实现为单楼阁 + 单大灯笼的精简构图，前景物什少于原图。
2. 原图山水为手绘水墨的丰富皴擦层次；本实现用水墨置换滤镜近似，
   笔触变化不如手绘细腻。
3. 原图暖光源更多（庭院灯火成排）；本实现主要暖光为窗棂 + 大灯笼 + 湖岸灯火，
   右半幅夜空相对空旷（月亮平衡）。
4. 卡片插画为精致矢量水墨风，原图为更写意的手绘水墨；神似而非笔笔相同。
5. 手机 Hero 为重新构图（非等比压缩），景物相对位置与原图手机稿不完全一致，
   但月/阁/灯/山/水齐全、无裁切、无遮挡。
