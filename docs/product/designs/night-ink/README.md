## 不得修改的设计

- 整站深青夜景、暖金字色、朱砂印记、温润宣纸、灯笼／楼阁／月夜远山／桃枝。**禁止**改成白底 SaaS、黑金金融盘或五颜六色游戏页。
- 桌面：顶栏导航 → 月夜山水主视觉（品牌标题居中） → 第一排四张大宣纸入口 **今日运势／桃花姻缘／事业财运／流年运势** → 底部传统圆形入口。
- 手机：保留同一深青＋宣纸美术，不直接把桌面内容压到手机宽度；首屏品牌、月夜、四大入口与底部导航可读。
- 音乐是**全站必须始终可见的功能入口**：桌面顶栏右侧「♫ 古风音乐」，手机首屏顶栏可见音乐按钮，点击展开播放／暂停／音量；正常默认静音。路由前台切换持续播放，进入后台必须停止，勿自动重启。
- 音源应复用现有 `web/visual-prototype/public/music/quiet-waters.ogg` 与 `src/public/MusicPlayer.tsx`，不得重新使用未经授权的网络歌曲或凭空声明自动播放成功。
