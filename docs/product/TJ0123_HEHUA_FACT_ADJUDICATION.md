## 2. 冲突结构：四项真冲突，其余是详略差

条件要素×表述矩阵全表见登记 §CONDITION_MATRIX（11 要素 ×
F1–F6/HX）。真冲突（同要素不同门槛/有无、或同槽位不同取值）：

| ID | 冲突 | 要点 |
|---|---|---|
| C1 | F1 月集 vs F4 化月集合 | 018-C 逐月计算在案：五对全部分歧，如甲己 F1 要求三/五/六月在 F4 为暗秀/不化/不化，F4 化月含七、十一月为 F1 未要求；戊癸 F1 要求五月在 F4 为不化 |
| C2 | F1 妬合字 vs F3 妬化字 | 同节同槽位（第三干出现则不化），五对中三对触发字不同（甲己戊/乙、乙庚甲/辛、戊癸己/壬），两对相同（丙辛丁、丁壬丙）；无论读作一机制两传述还是两机制，编码必选边（审定点 AP2） |
| C3 | F1 列举月集 vs F2 旺气架构 | 架构级分歧：固定月集 vs 日辰实际旺气（月中/时上），对同一命盘可结论相反 |

不是冲突的详略差（登记 D1–D5）：有二则化只见於甲己句（缺席
非矛盾，向他对推广是解释步）；受气临官/喜时是逐对附加项；
F2 要旺与 HX 要衰是对象不同（化气格 vs 从化象），极性相反
不构成同对象冲突，但下游不得错接；F5 独合与 F3 有二是跨书
流派差候选；F1 内部「间之/柱有」两式是解析未定（D5）。
另：戊癸 F1 月集含 unresolved_token「丙」（018-C 在案），该
对连表述自身的月集都不完整（命题 P5）。**流派归属**：F1–F4
与 HX 同属三命通会体系（同书内分歧），F5/F6 属滴天髓原注/
任氏层（未登记）；全部并列、不裁定、不统一。

**司令不在矩阵内**：11 要素中 commander 一行全表述 absent——
逐对表述用月支集、通则用旺气、化象用支组与旺衰，没有任何

常见推论不成立；司令试点不是合化任何表述的输入（命题 P14）。

## 3. 三层事实审计与逐项判定（登记 §FACT_LAYER_AUDIT、§PROPOSITION_AUDIT，18 项）

- **(a) 干合关系事实**：已存在且已验证（P1 名册、P2 在场，
  fact_ready）。口径差一处：现行事实是任意柱对在场、不标示
  日干参与，而 doctrine 只取日干（P3，presence_only）——事实
  是化气条件的超集，筛选属实现细节（阻塞项 B6），不另立层。
- **(b) 条件要素事实**：月支值 fact_ready；妬合/妬化字在场、
  有二计数、受气临官/喜时在场、辰在场均为
  fact_ready_as_presence_only（在场可算、效力不可算，P6/P7/
  P9/P10/P11）；阻字效力 blocked_by_formulation_conflict
  （P8，即 C2）；旺气 blocked_by_missing_layers（P12：旺相
  框架只有登记文本，无可执行旺气定义）；根气/有气
  blocked_by_missing_layers（P13）；F1 月集归属
  adjudication_required（P4：算它即预选 F1）；戊癸月集
  blocked_by_unresolved_token（P5）。
- **(c) 化气成立判定**：裁定层、非事实（P16，
  adjudication_required = 用户级 P-D1）；从化象成立另属
  blocked_by_missing_layers＋分类待裁（P15 = P-D2）；消费面
  现状 consumer_not_unlocked（P17）；由合化推吉凶 prohibited
  （P18，逐月表贵贱状态词是断语登记、不是结论）。

## 4. 切片结论：SLICE_SPEC = None

不出事实层切片（登记 §SLICE_DECISION，审定点 AP1）。理由与
三刑切片的成立前提正相反：三刑是事实不存在且有消费方在等；
合化是关系事实已存在、要素事实属柱面转写（任何未来实现可
由命盘事实直接计算）、真正缺的是表述采用（用户裁定）与旺
气/根气定义层。若按某一表述的要素集预建事实层（按 F1 月集
报「月条件满足」、按某一字集报「阻字」），字段选择本身即
裁定——本批拒绝以基础设施预裁定。可接受的回退形态只有表述
中立的原始转写（月支值、干在场柱位/计数、辰在场），且其无
现行消费方，本批仍不建议立项（与 S4 审定 SLICE_SPEC=None
同例）。本批产出即 P-D1 裁定所需的全部审定材料。
