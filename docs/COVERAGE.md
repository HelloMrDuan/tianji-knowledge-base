## 平台调用约束

```text
用户输入
  ↓
确定性计算引擎
  ↓
结构化结果
  ↓
按 domain / school / ruleset / license 检索 Canonical
  ↓
返回文本 + repo/path/commit + license
  ↓
LLM 负责解释
```

禁止：

- 让 LLM 猜四柱、排盘、起局、起卦等可计算结果。
- 不同紫微/奇门/风水流派无声明混用。
- REFERENCE_ONLY / NON_COMMERCIAL / COPYLEFT 内容自动晋级商业 Canonical。
- 没有检索依据时生成“古籍说”“大师认为”等伪引用。
