# 大六壬 Phase 1 证据边界

核心选段来自《六壬大全》四库提要及正文、《六壬指南》传世电子本，
固定上游 commit/blob；单一电子整理来源标 C，并不等于已与刊本多版校核。
《六壬断案》仅登记候选地址、版本与公共领域依据，不把未核正文加入正式库。

九宗门保留各自原文、条件、结果与例外接口，均为 partially_structured。
涉害/渉害保留文字异名；不把旧引擎的八个函数数目当成九宗门的穷尽证明。
完整取初传、涉害深浅与伏吟/返吟的特殊中末传分支尚未编译。
`follow_transmissions` 只计算已给定初传沿天盘的普通续传，不执行初传选择。

月将、天地盘、四课和十干寄宫复用原 Canonical 表，不重做旧数据。
十二天将分别记录五行、象义、古籍吉凶分类与位置原句；吉凶为原文语义属性，
不产生新的事件预测。天后选段“位居前一”和其他段落后位的疑异保留待核，
不据此重新排将。贵人昼夜表保留两种显式 variant；该表尚未逐句古籍核定，
规则保持部分结构化，不能因查询接口可运行而升级为古籍核定的 executable。

现代 kinliuren MIT 源码只用于已有接口定位，证据 D 留在 quarantine，
与规则中的 C 级经典证据分别记录。正式检索只使用经审查的短选段和结构化实体。
